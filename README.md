# GWN plugin releases

Signed builds of Great White North Design plugins (GWN Email Money Transfer, GWN e-Transfer, GWND Fulfillment).
Stores update automatically from `<plugin>/info.json`; every zip is Ed25519-signed and checked before install.
Source is private.

`<plugin>/<plugin>.zip`, where present, is always the newest build: the website's download buttons link to it.
